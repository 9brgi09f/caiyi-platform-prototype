# 彩翼平台 UAT 测试用例与流程剧本

> **版本**：V1.0  
> **日期**：2026-08-17  
> **适用对象**：业务验收人员、平台运营、企业用户、开发者、财务人员  
> **测试目的**：验证彩翼平台核心业务流程、角色权限、数据记录和异常提示是否完整可用。  
> **测试基线**：`彩翼平台原型方案/index.html` 中 2026-08-11 前已确认的功能为主；主子账号与岗位权限按 2026-08-15 产品方案作为扩展验收范围。  
> **范围排除**：本轮不验收“运营端账户对账”“财务端对账报表”；不触发真实支付、真实银行打款、真实税务开票、银行/金蝶生产写入。

---

## 1. 使用说明

### 1.1 执行规则

1. 每条用例执行后，在“执行记录”中填写：实际结果、通过/失败/阻塞、截图或业务单据编号、缺陷编号。
2. 所有新增测试数据必须带 `QA-TEST-` 前缀或“仅供测试、非真实”标识；不得使用真实身份证、真实营业执照、真实发票或真实收款账户。
3. 遇到外部系统步骤，仅验证平台是否正确生成待处理状态、接口状态或回传结果展示；**不得**向真实支付、银行、金蝶或税务系统提交生产业务。
4. 不通过直接修改 URL、浏览器控制台、接口参数等方式绕过页面或服务端校验。
5. 不操作归属不明、可能关联真实业务的智能体、结算单、提现单、发票或账户。

### 1.2 结果定义

| 状态 | 定义 |
|---|---|
| 通过 | 实际结果与预期结果完全一致，且无异常报错。 |
| 失败 | 功能可操作，但实际结果与预期不一致。 |
| 阻塞 | 因系统错误、缺少测试数据、外部环境或已知缺陷，无法继续执行。 |
| 不适用 | 当前环境未部署该模块、角色无测试入口或经项目负责人确认不在本轮范围。 |

### 1.3 建议测试角色与数据

| 角色 | 建议账号 / 数据 | 使用范围 |
|---|---|---|
| 企业主账号 | `enterprise_member` 或专用企业测试账号 | 智能体市场、调用、充值、消费、发票申请。 |
| 开发者主账号 | `developer_admin` 或专用开发者测试账号 | 智能体创建、定价、收入、结算、提现。 |
| 平台运营 | `platform_operator` 或专用运营测试账号 | 审核、机构管理、规则设置、运营查询、发票审核、提现审核。 |
| 平台财务 | `platform_finance` 或专用财务测试账号 | 付款状态查看、财务记录与回传展示。 |
| 新注册用户 | 新建手机号，名称使用 `QA-TEST-姓名` | 注册、审核、免费体验资格验证。 |
| 子账号 | 新建/受邀测试手机号，名称使用 `QA-TEST-成员` | 成员邀请、岗位、权限与停用验证。 |
| 测试文件 | `QA-TEST-营业执照.pdf`、`QA-TEST-发票.pdf` 等 | 仅用于上传校验；文件需显著标明“仅供测试、非真实”。 |

## 6.2 上线验收建议

1. **P0 必须全部通过**：注册审核、身份与权限隔离、免费/付费扣减、智能体发布、提现主链路及已知 P0 缺陷必须无阻塞。
