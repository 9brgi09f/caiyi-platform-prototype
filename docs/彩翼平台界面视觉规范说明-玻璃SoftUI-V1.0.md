# 彩翼平台界面视觉规范说明（玻璃拟态 + Soft UI 进化版）

- 版本：V1.0（2026-08-31）
- 适用端：彩翼平台全部 Web 端（企业用户端先行，运营端 / 渠道端 / 开发者端按同一规范套用）
- 基准实现：`user/_glass-soft-skin.css`（共享皮肤，叠加于 `_bento-lite-skin.css` 之上）
- 基准页面：`user/index.html`（概览）、`user/invoice-list.html`（列表）、`user/invoice-add.html`（表单）、`user/member-view.html`（详情）

---

## 1. 风格定位

浅色玻璃拟态（Glassmorphism）+ Soft UI 柔和立体光影，面向"政企 + C 端"混合受众：干净、轻科技感、长期看不累。

三条核心设计原则（所有取舍都由此推导）：

1. **分层材质**：阅读区（大面板、表格、表单）用近实白，保证信息清晰；点缀区（统计卡、侧栏、页签、弹窗）保留玻璃通透，承载风格识别度。
2. **三层结构**：背景底色 → 环境光 → 玻璃面，三层缺一不可。面板不允许做成"纯白纸贴在彩色背景上"（透光率不低于 10%）。
3. **边缘跟随材质**：半透玻璃面用亮色描边（深边压在玻璃上显脏）；近实白大面板用投影 + 亮边定义边缘；信息块用同色系淡蓝灰细边。


另加两个固定光斑（`::before` / `::after`，260px 异形圆、`filter:blur(8px)`）：右上 `rgba(140,193,255,.10)` 旋转 21°；左下 `rgba(182,154,255,.08)` 旋转 -18°。

## 3. 布局规范

| 区域 | 规则 |
|---|---|
| 顶栏 | 固定顶部，高 68px，z-index 100 |
| 侧栏 | 固定左侧，宽 260px，`top:68px; bottom:0`，可滚动 |
| 主内容区 | `margin-left:260px; margin-top:68px; padding:32px 32px 48px` |
| 页头 | 标题与顶栏间距 32px；**含返回链接的详情页页头统一下移 14px**（`padding-top:14px`） |
| 返回链接 | 标题上方独立一行，`← 返回{来源页面名}`，13px / 600 / `--glass-blue-deep` |
| 卡片栅格 | KPI 卡组间距 16px；卡片间距 16–18px |
| 响应式 | ≤900px：侧栏转为静态流式、主区 `margin-left:0`，padding 收缩 |

列表页标准结构：`页头 →（可选 KPI 卡组）→ 筛选/工具栏面板 → 表格 → 分页条`。
详情页标准结构：`返回链接 → 标题（渐变短杠）→ 信息卡（字段块网格）→ 时间线/明细`。
表单页标准结构：`返回链接 → 标题 → 分组表单卡（field-grid 两列）→ 底部操作条`。

## 4. 组件规范要点

### 4.1 KPI 统计卡（全站统一）

- 18px 圆角玻璃面（`.62`）+ Soft UI 双阴影 + `blur(20px)`；
- 标签：`--glass-muted` 小字 + 7px 蓝圆点（外晕 4px）；
- hover：浮起 -3px + 阴影加深；`prefers-reduced-motion` 时禁用过渡；
- 概览页三张卡可用 145° 微渐变表面 + 首卡渐变数字；子页面（充值/彩豆/消费）用纯玻璃面 + 纯色数字，语义色（正/负/警示）保持页面原定义。

### 4.2 表格

- 表头：`rgba(250,252,255,.80)` 底 + `--glass-muted` 文字；
- 行分隔：`rgba(148,170,214,.16)`；行 hover：`rgba(255,255,255,.52)`；
- 行内文字 `#3d4c68`；数据行保持半实，禁止多层透明叠加导致发虚。

### 4.3 表单控件

- 边框 `rgba(148,170,214,.55)` + 底 `rgba(255,255,255,.78)` + 内高光；
- focus：蓝边 + 3px 蓝晕，去 outline；
- 禁止白边框（在浅底上隐形，已作为历史缺陷修复）。

### 4.4 按钮

- 主按钮：主渐变 + 白字 + 投影；hover 加深；`:active` 内阴影 + 下移 1px（可按压感）；
- 次按钮：145° 白渐变面 + 蓝灰文字 + Soft UI 双阴影；hover 文字变 `--glass-blue-deep`。

### 4.5 页签 / 筛选 chips / 分页

- chip：`.55` 白玻璃 + 亮边；选中：主渐变 + 白字；
- 分页条：上方 `rgba(148,170,214,.16)` 分隔线；左"共 N 条记录"（`#7b8aa6`），右 32px 玻璃按钮；当前页主渐变填充；禁用态不透明度 .42；
- 每页条数建议：表格 8 条、紧凑记录 5 条；筛选条件变化时回到第 1 页。

### 4.6 弹窗 / 抽屉

- `.86` 白 + 亮边 + 20px 圆角 + `blur(20px)`；头/底部分隔线 `rgba(148,170,214,.20)`。

### 4.7 侧栏导航

- 未选中：`#44536e` + 半透明图标底；hover：`.47` 白底；
- 选中：`.64` 白玻璃 + 亮边 + 浮起阴影 + 渐变图标（白 glyph）+ `--glass-blue-deep` 文字；
- 侧栏整体 `.23` 白 + `blur(14px)`，保持"贴在环境光上"的通透。

## 5. 动效

- 统一 `transition: .15s–.2s ease`；
- 卡片 hover：`translateY(-3px)`；概览列表项 hover：`translateX(2px)`；按钮 `:active`：`translateY(1px)` + 内阴影；
- 所有位移/过渡动画必须包 `@media (prefers-reduced-motion: reduce)` 降级。

## 6. 落地方式（给研发）

1. 页面 `<body>` 挂 `bento-lite` 类；概览页额外挂 `overview` 类。
2. 按顺序引入：基础皮肤 `_bento-lite-skin.css` → 共享视觉皮肤 `_glass-soft-skin.css`，页面私有样式置后。
3. 新页面优先复用既有类名（`.panel` / `.content-card` / `.stat-card` / `.data-table` / `.filter-bar` / `.input` / `.btn-primary` / `.btn-outline` / `.badge-*` / `.pager` / `.records-footer` …），样式即自动生效；不要新造并行类名。
4. 页面历史皮肤与新皮肤冲突时，只允许在页面 `<style>` 末尾追加"恢复块"做最小化中和，禁止改共享皮肤去迁就单页。
5. 共享皮肤变量集中在 `:root`（`--glass-ink / --glass-muted / --glass-blue / --glass-blue-deep / --glass-line / --glass-surface / --glass-surface-strong / --glass-shadow`），调风格只改变量，不改选择器。

## 7. 验收清单（Do / Don't）

**Do**

- 阅读区近实白、点缀区通透，层次三段论（背景 → 环境光 → 玻璃）；
- 文字一律高对比实色，投影环境下仍可读（次级文字不低于 `#475672`）；
- 控件边框清晰可见；返回链接、分页、筛选在各页位置一致；
- 同一页面同类组件共用同一套材质参数。

**Don't**

- 大面积深色 / 高饱和渐变铺底；
- 面板做成 100% 实白失去"透"（≤.90 且需保留模糊与投影）；
- 玻璃卡压深色描边、表单控件用白描边；
- 文字置于多层透明叠加之上导致发虚；
- 单页私改共享变量或复制整套皮肤造成分叉。
