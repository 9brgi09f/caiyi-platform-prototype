## 原型采用的规则

1. 年包：由运营自定义名称、价格、赠送比例与在售状态（在售最多 6 个，价格越高总彩豆须越多），价格 × (1 + 赠送比例) = 年度总彩豆；自购买日起 12 个月有效，基础与赠送同一有效期，到期清零；可重复购买，各自计有效期。
2. 升级：生效中年包可升级到任一价格更高的在售年包，由用户选择；补差价 = 目标价格 − 原年包已付金额；补发彩豆 = 目标总彩豆 − 原年包总彩豆；有效期不变；不支持降级。剩余有效期不足 90 天时提示可单独购买。
   - 入门 → 标准：补 ¥25,000，补发 35,598（基础 25,000 + 赠送 10,598，其中 598 为原 5,980 基础彩豆赠送比例从 30% 提到 40% 的补足）
   - 入门 → 专业：补 ¥55,000，补发 83,696；标准 → 专业：补 ¥30,000，补发 48,098
3. 单次充值：100 / 500 / 1,000 元或 10–10,000 元自定义，长期有效。限时充值赠送：运营配置统一比例（默认 100%）与起止日期（默认 2026-11-15 至 2026-12-31），档位与自定义金额同比例赠送，企业与个人每次充值都送；赠送彩豆长期有效、不开票、不分账；比例不低于年包时仅提示不拦截。
4. 免费彩豆仅个人身份享有，包含月度赠豆（每月 50，当月首次登录到账）和每日登录赠豆（每日首次登录赠 5，月上限 50），两项可分别开关；当月有效，可用于全部智能体，年包用户同样享有。企业身份不赠豆，单位账户不发月度赠豆。
5. 现有“新用户每个智能体 N 次免费体验”不变，与免费彩豆相互独立。
6. 扣减顺序：个人身份 免费彩豆 → 年包彩豆（先到期先用）→ 充值彩豆；企业身份 年包彩豆 → 充值彩豆。
7. 开票与分账：年包、升级、单次充值订单按实付金额开票；赠送彩豆、免费彩豆不开票，其消费不参与开发者分账。消费发票仅限充值彩豆部分，年包彩豆消费不再单独开票（口径待财务确认）。
8. 不做退款。

## 已确认（2026-11-18）

免费彩豆为个人身份的月度赠豆加每日登录赠豆（2026-11-22 恢复月度赠豆），单位账户不送，不另设一次性注册赠豆；新用户免费体验次数不动；升级后有效期不变；免费彩豆与赠送彩豆消费不给开发者分账；运营配置页按企业用户端视觉规范调整；年包由运营自定义；升级时用户可在价格更高的在售年包中选择目标。

## 原型边界

- 数据存于浏览器 `localStorage`（`caiyi.beanplan.v1` 账本、`caiyi.beanplan.config.v1` 配置），业务日期固定为 2026-11-18；支付为模拟成功。
- 个人身份可从侧栏进入发票管理。预置 2 笔待开票充值（100 元无赠送；100 元含限时赠送 100），消费可开 255 元（40 + 3 + 212）。含赠送示例 USE20261117143026 的消费详情逐批展示折算：157 × 1 + 110 × 0.5 = 212 元。默认使用个人抬头，可自行添加企业抬头。申请、订单、消费与常用抬头均按当前身份读取。
- 财务端、运营端充值记录与对账、开发者结算未按年包订单与扣减来源改造，在 PRD 中描述。
- 消费记录仅保留 2026-08-05 以后的演示数据，更早的历史消费单不再展示；发票列表中的历史发票为静态数据。
