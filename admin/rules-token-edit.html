计费规则

配置平台算力成本单价和免费使用次数；智能体的按 Token 或按次定价由开发者设定，平台按规则核验并结算。

算力成本单价（结算扣除口径 · 兼开发者定价下限）

每 token 算力成本 = 彩豆

说明：平台算力成本价，不影响用户扣费，承担两个职责：① 开发者月度结算时按智能体实际消耗 token 计「算力成本费」，先按 开发者80%/平台20% 分成、再从开发者分成中全额扣除（最终收入 =用户消耗彩豆 × 80% − 算力成本彩豆）；② 作为开发者定价下限（换算率不得低于此值）。次月 1 日生效并留存修改记录。

成本测算示意
智能体本月消耗 5,000,000 token → 算力成本 ≈ 500 彩豆 ≈ ¥5.00，结算时先按 80/20 分成、再从开发者分成中全额扣除

免费使用次数

每位新注册用户对每个智能体免费使用 次

新注册用户获得一次性免费权益；每个智能体的免费次数用完后，按该智能体已生效的计费方式扣费，不再重置。填 0 表示不提供免费次数。免费调用期间的算力成本由平台承担，适用于按 Token 与按次计费智能体。

统计口径：按“平台个人账号 × 智能体”独立累计，用户注册时初始化免费次数；规则调整仅适用于调整后新注册用户，已注册用户保留注册时获得的免费次数，并保留修改记录。
