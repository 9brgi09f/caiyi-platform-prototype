日期更新模块功能说明
2026-11-18年包与免费彩豆 本次更新账户充值新增年包（默认入门版 / 标准版 / 专业版，赠送 30% / 40% / 50%，12 个月有效，运营可自定义），可重复购买，每份单独计有效期（年包升级本期不做）；单次充值为 100 / 500 / 1,000 元三档及自定义金额，长期有效，支持限时充值赠送（运营配置比例与起止日期，默认 1:1，档位与自定义金额同比例，赠送部分不开票，消费开票按“实付 ÷ 到账彩豆”折算）；个人身份每月首次登录赠 50 彩豆、每日首次登录赠 5 彩豆（月上限 50），当月有效，企业身份不赠豆；彩豆管理按免费 / 年包 / 充值分类展示余额与到期日，扣减顺序为免费 → 年包 → 充值；赠送与免费彩豆不开票、不参与开发者分账，消费记录显示扣减来源，年包订单按实付金额开票，消费年包彩豆与充值彩豆均可按批次本金分摊金额开消费发票（用完时合计等于实付）；运营端彩豆规则统一配置年包、单次充值、充值赠送与免费彩豆并留痕，规则设置页改为企业用户端玻璃 Soft UI 风格。退款业务确认不做，三端停止加载退款入口。
2026-11-04智能体首页等交互调整新增智能体广场：分政府采购专区与国企采购专区，支持搜索、按功能类型 / 角色 / 采购阶段 / 开发方筛选及收藏；来源标识按应用类型自动判定，平台托管显示“平台官方”，协议接入、外部跳转显示“生态伙伴”；企业用户端“智能体市场”菜单改为“我的收藏”，按专区查看、搜索和排序已收藏智能体；开发者发布与运营修改智能体时，“产品分类”“智能体属性”“智能体标签”改为专区、适用群体、采购阶段、功能类型（均为多选），存量智能体专区默认政府采购专区，采购阶段与功能类型留空由运营维护。
2026-09-14充值退款与消费退豆三端统一从“退款管理”菜单进入，默认无菜单权限，按账号授权后才能查看和处理；支持企业用户退款申请、开发者审核及平台终审，取消计费规则中的退款开关；充值退原单剩余本金，申请冻结彩豆，平台审核后线下付款并登记回单；消费经开发者和平台两级审核后退回原扣彩豆及原充值来源，不退现金；开票中、已开票及已进入结算的消费禁退；支持撤销、驳回、余额与结算调整回显，本期不对接银行及金蝶退款接口。
2026-09-13企业用户端 · 好友邀约仅在企业用户端新增“邀请好友”“我的邀请人”菜单，沿用玻璃 Soft UI 风格；支持邀请码与邀请链接复制、二维码生成与保存、邀请记录查询筛选及分页；好友邀请码随企业注册流程保留，与渠道商邀请码独立；支持邀请码校验、绑定前确认、邀请人信息与绑定记录查看，主子账号邀请关系独立，绑定后不可更改；移除微信分享、短信分享及更多方式按钮，绑定方式改为无底色普通文字。
2026-08-27单位彩豆管理与授权消费单位彩豆全员共有，不再区分个人与单位彩豆：有充值权限即可充值入企业账户，付款可选个人支付或机构对公账户；有智能体市场权限即可消费，取消成员额度制；充值记录全公司可见，有消费记录菜单权限即可查看全公司消费记录；发票管理权限可对全公司充值与消费开票；保留余额预警与机构对公账户维护。
2026-08-18主子账号与岗位权限机构主账号可新增子账号、分配多个岗位并配置菜单与操作权限；未注册手机号由系统创建平台账号并短信发送一次性临时密码，首次登录后需修改密码；支持待首次登录成员的岗位调整、重发临时密码与取消成员。本期不含彩豆管理。
2026-08-11用户注册与账号体系新增个人用户与企业/机构注册；个人用户与机构用户均经运营审核通过后激活账号；统一手机号对应平台个人账号，并支持机构成员关系与角色管理。
2026-08-11注册审核与通知补充企业/机构审核、注册待办、站内消息与短信通知规则；个人用户注册成功后告知体验权益。
2026-08-11智能体双模式计费开发者创建和编辑智能体支持按 Token、按次两种计费方式；运营端统一配置计费规则。
2026-08-11新用户免费体验运营端可配置新注册用户每个智能体的免费次数；用户端新增剩余次数展示、调用扣减、免费体验记录和运营权益查询。
2026-07-20彩翼平台整体功能完成用户、开发者、平台运营、财务等核心角色端原型，以及注册、智能体调用、计费结算、充值开票与对账等主要业务流程设计。
